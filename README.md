# 🐍 Snake Game

Simple Snake game (HTML + CSS + JavaScript). Kono build step lagbe na.

## Controls
- Keyboard: Arrow keys ba WASD
- Mobile: canvas e swipe, ba on-screen buttons

## GitHub Pages e deploy korar steps
1. GitHub e notun repository banao (e.g. `snake-game`).
2. Ei folder er sob file repo te upload koro (`.github` folder shoho) — `main` branch e.
3. Repo te jao: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Actions** tab e deploy workflow cholbe. Sesh hole link pabe:
   `https://<your-username>.github.io/<repo-name>/`

## Local e chalate
`index.html` file ta browser e open koro.
